# DouYin Comments Tool

一个在 Windows 本机运行的抖音评论检索工具。粘贴视频链接，采集评论和回复，按抖音号、关键词或时间查找，结果可以在页面查看，也可以导出 TXT。另支持读取账号公开的喜欢列表和个人主页「推荐」列表。

采集内核使用 [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)，前端、任务管理、搜索和本地存储由本项目实现。数据和登录资料保存在本机。

## 能做什么

| 功能 | 说明 |
| --- | --- |
|   视频评论   | 支持完整链接、短链接和分享文本；采集主评论及回复 |
| 按抖音号查找 | 精确匹配公开抖音号，可单独补齐缺失的作者资料；昵称不作为账号依据 |
|  按内容查找  | 包含匹配、近似匹配；繁简体、全半角和英文大小写自动归一，结果保留原文 |
|   时间筛选   | 评论按发布时间筛选、从新到旧排列，显示北京时间 |
|  喜欢与推荐  | 输入抖音号，读取公开列表；可限制最近 N 条，也可指定行为时间范围，限制见下文 |
|  历史与导出  | 保存任务和断点，支持停止后继续、重新采集、分页查看及 TXT 导出 |

喜欢与推荐按平台返回的最近点赞／推荐顺序保存。数量限制计算去重后的结果；达到上限时显示「部分完成」，不代表已取完整列表。

**时间范围有一项限制：** 当前喜欢接口没有可靠的逐条点赞时间，暂不能按点赞时间范围采集。推荐列表只接受能与目标账号核对的推荐时间。遇到缺失或冲突的行为时间会提示并停止，不用视频发布时间代替。

## 怎么运行

准备 Windows 10/11、Google Chrome、Python 3.12、[uv](https://docs.astral.sh/uv/getting-started/installation/) 和 Node.js 22 或更高版本。`uv`、`node`、`npm` 需要能在终端中使用。

1. 下载仓库 ZIP 并解压，或克隆仓库到可写目录。路径可以包含空格。
2. 双击 **初始化环境.cmd**，等待依赖安装和前端构建完成。首次需要联网。
3. 双击 **启动工具.cmd**，浏览器会打开 [本地页面](http://127.0.0.1:8765)。
4. 在页面点击登录，在工具打开的专用 Chrome 中扫码。之后的任务复用这个登录状态。

也可以在项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

初始化脚本按锁文件安装依赖，并检查内核和 Chrome。它不会安装系统软件；缺少 Python 3.12 时，
可先执行`uv python install 3.12`。

运行时请保留服务窗口。退出前先停止采集，再在服务窗口按 `Ctrl+C`。只关闭网页不会停止服务。

## 怎么使用

**查评论：** 粘贴视频链接 → 创建任务 → 开始采集 → 填写筛选条件 → 搜索或导出。多个筛选条件同时填写时，结果需要全部满足。导出包含当前筛选下的全部匹配记录，不只当前页。

**查喜欢／推荐：** 切换到对应页面 → 输入公开抖音号 → 填写数量或时间条件 → 创建并开始采集。数量留空或填 `0` 表示不限。「推荐」指个人主页里主动推荐的作品，不是首页推荐流；「喜欢」也不是收藏。

平台明确返回未公开时，页面会提示对应列表未公开。空列表、登录失效和请求失败会分别处理，不会直接判成未公开。

停止任务会保留已经保存的结果和断点；重新采集会创建新批次，旧结果仍在历史任务中。

新任务默认不勾选「采集后核实作者抖音号」，先完成内容采集。接口已有的抖音号照常保存，缺失的显示「未提供」；需要补齐时点击「核实作者」，只处理已有结果。评论、喜欢和推荐都支持这一操作。历史任务保留原设置，可在停止后修改。

作者抖音号未补齐时，关键词搜索仍可正常使用，按抖音号搜索可能漏掉部分结果。搜索未命中不能证明该账号没有评论。

## 采集原理

![采集原理：前端创建任务，经本地服务调用 MediaCrawler，逐页保存数据与断点，供搜索和导出使用](docs/images/architecture.png)

Web 服务管理任务和专用 Chrome，采集 worker 调用 MediaCrawler 的 `DouYinCrawler.start()`。评论走内核的评论分页；喜欢、推荐和作者核实通过扩展接入同一个客户端。每页结果与游标一起写入 SQLite，搜索与导出读取已保存的数据。

内核固定在提交 `5d547f45862ca2d4b404e5a51775879d579b29d4`，兼容补丁为 `workbench.1`。源码随仓库保存，初始化不需要再拉取上游。补丁、原始文件和校验清单见 [vendor/patches](vendor/patches/README.md)。

请求使用单并发，间隔从随机 2–4 秒开始，每连续成功 20 次，依次缩短到 1.5–2.5 秒、1–2 秒。失败会退避，限流会冷却；需要人机验证时暂停，等待用户在浏览器完成。冷却状态跨任务保存，重启不会清除。详细调用关系和请求策略见 [原理说明](docs/architecture.md)。

登录过期后等待重新登录，不计为验证码事件；明确私密的列表不会触发降速。连续 5 次网络或平台服务暂时故障会暂停采集，保留已保存结果和断点，可稍后继续。

## TXT 格式

评论每条五行，记录之间空一行，不重复写视频链接。下面均为虚构示例：

```text
用户名：示例用户甲
抖音号：example_user_a
评论内容：这条视频讲得很清楚
时间：2026-10-06 14:23:08
IP 属地：广东

用户名：示例用户乙
抖音号：example_user_b
评论内容：謝謝分享
时间：2026-10-05 20:11:36
IP 属地：未提供
```

喜欢和推荐导出相同字段：

```text
视频标题：一段旅途记录
作者名称：示例作者
作者抖音号：example_author
发布时间：2026-10-06 14:23:08
视频链接：https://www.douyin.com/video/1234567890
```

这里的「发布时间」是视频发布时间，不是点赞／推荐时间。时间按源数据精度显示到秒，缺失字段写「未提供」。文件采用 UTF-8 BOM，字段内换行写成 `\n`；未采集完整时，文件开头会注明状态。

## 需要知道的限制

- 只能获取平台当前返回的可访问内容。删除、隐藏或受权限限制的评论可能取不到，结果数也可能与页面显示的总数不同。
- IP 属地是接口提供的公开地区信息，不是实际 IP 地址，也不用作者主页属地替代。
- 抖音接口可能变化，登录可能过期。使用 MediaCrawler 不代表不会遇到验证；工具不自动破解验证码。
- 服务默认只监听本机 `127.0.0.1:8765`，按本机单用户工具使用。

## 本地文件

```text
backend/              接口、任务、内核适配、搜索与存储
frontend/             React / TypeScript 界面
tests/                离线回归测试
docs/                 原理说明与图片
vendor/MediaCrawler/  固定版本的上游源码及许可证
vendor/patches/       兼容补丁、原始文件与校验清单
data/                 本机运行数据，不入库
```

`data/` 包含采集数据库、登录资料、日志和备份，已加入忽略规则。不要把整个项目目录直接打包分享。正常退出后可以自行备份 `data/`，恢复时放回原处。

专用 Chrome 使用 `data/chrome-profile`，与日常浏览器资料分开。提交问题时请去掉日志中的账号、链接和本机路径，不要附 Cookie 或浏览器资料。更多说明见 [SECURITY.md](SECURITY.md)。

## 开发与检查

完成初始化后，在项目目录运行：

```powershell
$env:PYTHONUTF8 = '1'
$env:DOUYIN_DATA_DIR = Join-Path $PWD 'data\test-app'
New-Item -ItemType Directory -Force data | Out-Null
.\.venv\Scripts\python.exe -m pytest -q --basetemp=./data/test-run
.\.venv\Scripts\python.exe -m backend.check_engine
npm.cmd --prefix frontend run build
```

前端开发：在 `frontend` 目录运行 `npm run dev`，同时运行后端 `.\.venv\Scripts\python.exe -m backend.app`。验证范围与注意事项见 [VERIFICATION.md](VERIFICATION.md)。
